# Elias Hotel Android App

Mobile Android app for Elias Hotel sales tracking.

Features:
- Add products and change current prices
- Record quantity, unit price, date and total
- Daily / monthly / yearly reports
- Current-month history
- Historical sales keep the price used at the time of sale
- Offline storage in the app

## Build APK on GitHub
1. Create a GitHub repository.
2. Upload all files in this project.
3. Open **Actions** → **Build Elias Hotel APK** → **Run workflow**.
4. When the workflow finishes, open the run and download the **Elias-Hotel-APK** artifact.
5. Extract the ZIP and install `app-debug.apk` on Android.

No Android Studio is required for this GitHub build workflow.
